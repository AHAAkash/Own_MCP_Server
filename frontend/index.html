MCP explained

Model Context Protocol (MCP) is an open standard that lets an AI application connect to external tools and context through a consistent client–server interface. Think of it as a common plug: an MCP server describes what it can do, and an MCP client can discover and request those capabilities.

We use MCP to connect models to useful, permissioned capabilities—such as searching approved project files—without building a separate integration for every AI app. The client stays in control of what it shares, while the server validates and performs the requested operation.
